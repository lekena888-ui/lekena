EXPLORE LESOTHO TOURISM WEBSITE

PROJECT FILES
- index.html: Home page
- about.html: About Lesotho
- destinations.html: Destination search and filtering
- gallery.html: Gallery with carousel and image viewer
- contact.html: Booking and contact forms
- style.css: Sky-blue styling and responsive layout
- script.js: JavaScript features

HOW TO RUN
1. Extract the ZIP folder.
2. Keep the files together.
3. Open index.html in a web browser.
4. Internet access is needed for Bootstrap and the photographs.

ASSIGNMENT FEATURES
- Five connected pages
- Semantic HTML5 structure
- External CSS, responsive design, grid/flex layout and hover effects
- Bootstrap 5 navbar, cards, carousel, modal, accordion, alerts, buttons and forms
- Destination search and category filtering
- Photo viewer with next/previous controls
- Dark/light mode saved using localStorage
- Booking and contact form validation
- Booking cost calculator
- Dynamic destination information and current year
- Alt text and labels for accessibility
